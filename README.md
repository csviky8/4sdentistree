# 4S Dentistree

Premium static HTML redesign using the clinic’s original content and images.

## Open directly

Double-click `index.html` in this folder. Pages, images, CSS, JavaScript, menus and image galleries use relative paths and work with file:// URLs. Keep the whole folder together. Vimeo videos and external contact links require internet access; a video provider may require HTTP hosting for playback.

## Optional local server

Open a terminal in this folder and run `npm start` (or `node server.cjs`). Visit http://127.0.0.1:5173/. No npm install or build is needed. If the port is already in use, the preview may already be running.

## Hosting

Upload this folder’s contents to any static hosting service. Relative links work at a domain root or in a subfolder. Every page has a `.html` entry and original routes have directory aliases.

## Contents

Homepage plus nine menu pages, eight blog articles, 15 FAQs, 22 services, 23 clinical team members and 14 Vimeo players. Original images and optimized WebP copies are local. Telephone, WhatsApp, social and directions links open their real destinations.
